# AI Systems Workshop

One-hour workshop for businesses: **Building an AI Framework Around Your Business**

## Overview

This is a hands-on introduction to creating a managed AI system that runs business processes autonomously. Unlike step-by-step instruction workshops, this covers conceptual foundations:
- How to think about AI as infrastructure (not tooling)
- Where Composio + MCP fit in your stack
- Building blocks of an AI-driven business process
- Real examples from live systems

## Workshop Structure (60 minutes)

### Part 1: AI as Infrastructure (15 min)
- Traditional approach: Manual workflows → Human time
- AI approach: Define process → Agent runs it
- The role of agents, tools, and integrations

### Part 2: The Technology Stack (20 min)
- **Composio:** Multi-app orchestration and credential management
- **MCP (Model Context Protocol):** Standard for connecting Claude to tools
- **Agents:** Autonomous loops that call tools
- Real system example: How littleabigi.com email digest works

### Part 3: Building Your First AI System (20 min)
- Identifying high-volume repeatable tasks
- Mapping data sources (Gmail, Slack, CRM, etc.)
- Defining success (what "done" looks like)
- Workshop activity: Design one process from their business

### Part 4: Getting Started (5 min)
- Next steps
- Resources and follow-up

## Key Concepts to Convey

1. **Agent autonomy vs. automation:** Agents make decisions; automations execute steps
2. **Composio as a bridge:** Handles auth + multi-app credential management
3. **MCP as the language:** Standard protocol for connecting tools to Claude
4. **Cost shift:** From human time → compute (usually cheaper, always faster)
5. **Where it fails:** Ambiguous processes, requiring human judgment, edge cases

## Target Audience

- Founders, operations leaders, product managers
- Businesses with repeating manual processes (email triage, lead scoring, data syncing)
- No coding required to understand concepts
